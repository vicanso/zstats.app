## [0.1.0] - 2026-08-15

### 🚀 Features

- Editable config, and a hardware tab that folds quiet sensors
- Quieter app rows, and an empty alerts state that proves it is armed
- Snooze an alert's banners for an hour or three
- Pin list headers everywhere, and reopen with a clean slate
- Find big files from the boot volume's card, and act on them
- Adopt zstats 0.5 — pressure culprits, byte bar, footprint history
- Walk the home tree into three rankings, with trash for tagged caches
- Drill into a ranked directory, and step back for free
- Serve drill-downs from a pruned index instead of re-walking
- Group digits in the walk counters, and a clear-results control
- Clean-up hints and a one-click cleanup suggestion set
- Cover more tool caches in cleanhints, without volunteering user data for deletion
- Pick the folder the analyser walks, home by default
- Settings grow into a real window — nav, opacity, and an About page

### 🐛 Bug Fixes

- Keep History's two clocks from reading as one
- Make the large-files caption tell the truth about its rows

### ⚙️ Miscellaneous Tasks

- Run fmt, clippy and the test suite on every push
